可以。下面我直接给你一版**可开工的 Zotero 7 插件 MVP 接口清单 + TypeScript 模块骨架**。
先补一个现实判断：**现在已经有 Zotero 8 正式版，但它是在 Zotero 7 的新插件架构上继续演进的**。所以你这版 MVP 仍然可以按“Zotero 7 插件 API”为基线来设计，同时尽量避免写死旧式 DOM 注入，优先走官方提供的集成点，例如 item pane sections、settings panes、reader 集成点。这样后续兼容 Zotero 8 会更稳。([Zotero][1])

# 1. MVP 边界

这版只覆盖 4 条主链路：

1. **Reader 里选中文本后发起 AI 动作**
2. **右侧 Item Pane 展示论文 AI 洞察**
3. **把 AI 结果保存到 Zotero note / annotation**
4. **绑定 GitHub 仓库并做基础 paper-code 对齐问答**

先不做重画布，只做一个**Workspace 面板**，把卡片对象化存起来。

---

# 2. 你真正要依赖的 Zotero 官方扩展点

这几个是 MVP 的核心落点：

* **Custom Item Pane Sections / Info Rows**：适合做 AI Insight、Repo Binding、Usage 状态。官方明确建议插件用这个 API，而不是手工注入 item pane。([Zotero][1])
* **Zotero 7 新插件架构**：支持 restartless loading/unloading 和内建常见集成点，适合做稳定插件。([Zotero][2])
* **官方示例插件 `make-it-red`**：适合作为项目脚手架起点。([Zotero][1])

```ts
import type { InsightPack } from "../../types/paper";
import { paperService } from "../../services/paper/paperService";

class InsightSectionControllerImpl {
  private registeredID?: string | number;

  async register() {
    this.registeredID = Zotero.ItemPaneManager.registerSection({
      paneID: "vibe-insight-section",
      pluginID: "vibe-plugin@example.com",
      header: {
        l10nID: "vibe-insight-header",
        icon: "chrome://vibe/content/icons/16/insight.svg",
      },
      sidenav: {
        l10nID: "vibe-insight-header",
        icon: "chrome://vibe/content/icons/20/insight.svg",
      },
      onRender: async ({ body, item }) => {
        body.textContent = "Loading AI insight...";
        if (!item) return;

        const pack = await paperService.getCachedInsightPack(item.id)
          ?? await paperService.buildInsightPack(item.id);

        body.replaceChildren(renderInsightBody(pack));
      },
    });
  }

  async unregister() {
    if (this.registeredID) {
      Zotero.ItemPaneManager.unregisterSection(this.registeredID);
    }
  }

  async refresh(_itemID: number) {
    // 可选：触发重绘逻辑
  }
}

function renderInsightBody(pack: InsightPack): HTMLElement {
  const container = document.createElement("div");
  container.className = "vibe-insight-section";

  const summary = document.createElement("div");
  summary.textContent = pack.shortSummary;
  container.appendChild(summary);

  const ul = document.createElement("ul");
  for (const c of pack.contributions) {
    const li = document.createElement("li");
    li.textContent = c;
    ul.appendChild(li);
  }
  container.appendChild(ul);

  return container;
}

export const insightSection = new InsightSectionControllerImpl();
```

这个实现方向直接对齐 Zotero 官方 item pane section API。([Zotero][1])

```ts
import { repoService } from "../../services/repo/repoService";

class RepoSectionControllerImpl {
  private registeredID?: string | number;

  async register() {
    this.registeredID = Zotero.ItemPaneManager.registerSection({
      paneID: "vibe-repo-section",
      pluginID: "vibe-plugin@example.com",
      header: {
        l10nID: "vibe-repo-header",
        icon: "chrome://vibe/content/icons/16/repo.svg",
      },
      sidenav: {
        l10nID: "vibe-repo-header",
        icon: "chrome://vibe/content/icons/20/repo.svg",
      },
      onRender: async ({ body, item }) => {
        body.textContent = "";
        if (!item) return;

        const binding = await repoService.getBinding(item.id);
        if (!binding) {
          const btn = document.createElement("button");
          btn.textContent = "Bind GitHub Repo";
          btn.onclick = async () => {
            const repoURL = prompt("GitHub repo URL");
            if (!repoURL) return;
            await repoService.bindRepo(item.id, repoURL);
          };
          body.appendChild(btn);
          return;
        }

        const p = document.createElement("p");
        p.textContent = `Bound: ${binding.repoURL}`;
        body.appendChild(p);

        const refresh = document.createElement("button");
        refresh.textContent = "Refresh Repo Index";
        refresh.onclick = async () => {
          await repoService.indexRepo(item.id);
        };
        body.appendChild(refresh);
      },
    });
  }

  async unregister() {
    if (this.registeredID) {
      Zotero.ItemPaneManager.unregisterSection(this.registeredID);
    }
  }

  async refresh(_itemID: number) {}
}

export const repoSection = new RepoSectionControllerImpl();
```

```ts
import type { ReaderAction, SelectionPayload } from "../../types/chat";
import { chatService } from "../../services/chat/chatService";
import { workspaceService } from "../../services/workspace/workspaceService";

class SelectionActionsImpl {
  async register() {
    // 这里保留给 reader popup / context menu 注册
    // 具体接法取决于你最终采用的 toolkit/helper
  }

  async unregister() {}

  async handleAction(action: ReaderAction, payload: SelectionPayload) {
    switch (action) {
      case "explain": {
        const result = await chatService.askExplainSelection(payload);
        // 推到 side panel
        break;
      }
      case "code-align": {
        const result = await chatService.askCodeAlign(payload);

        break;

          itemID: payload.itemID,
          type: "paper-snippet",
          title: "Selected Snippet",
          content: payload.selectedText,
          sourceAnchors: [{
            itemID: payload.itemID,
            attachmentItemID: payload.attachmentItemID,
            page: payload.page,
            annotationKey: payload.annotationKey,
            selectedText: payload.selectedText,
          }],
          order: Date.now(),
        });
        break;
      }
      default:
        break;
    }
  }
}

export const selectionActions = new SelectionActionsImpl();
```

## 6.6 `src/services/chat/chatService.ts`

```ts
import type { AskInput, AskOutput, SelectionPayload } from "../../types/chat";
import { contextAssembler } from "./contextAssembler";
import { promptRouter } from "../ai/promptRouter";
import { llmClient } from "../ai/llmClient";
import { responseNormalizer } from "../ai/responseNormalizer";

class ChatServiceImpl {
  async ask(input: AskInput): Promise<AskOutput> {
    const ctx = await contextAssembler.assemble(input);
    const messages = promptRouter.buildMessages(input.mode, ctx);
    const raw = await llmClient.generate({
      messages,
      model: "gpt-4.1-mini",
      temperature: 0.2,
    });
    return responseNormalizer.normalize(raw, ctx);
  }

  async askExplainSelection(payload: SelectionPayload): Promise<AskOutput> {
    return this.ask({
      itemID: payload.itemID,
      mode: "explain-selection",
      query: "Explain this selected passage.",
      selectedText: payload.selectedText,
      page: payload.page,
      includeInsightPack: true,
    });
  }

  async askCodeAlign(payload: SelectionPayload): Promise<AskOutput> {
    return this.ask({
      itemID: payload.itemID,
      mode: "code-align",
      query: "Find the most relevant implementation in the bound repo.",
```

```ts
            localContext.selectedText,

      insightPack: insightPack ?? undefined,

    };
  }
```

# 7. 开发优先级清单

按真实施工顺序来。

## Phase 0：脚手架

* 基于官方示例或社区模板起插件
* 跑通 startup / shutdown
* 跑通 settings pane
* 跑通本地存储

官方示例和 Zotero 7 插件架构已经为这一步提供了稳定基础。([Zotero][1])

## Phase 1：Reader 选中即问

* 做 selection popup / context menu
* `SelectionPayload`
* `ChatService.askExplainSelection()`
* 侧边面板展示结果

## Phase 2：Insight Section

* `ItemPaneManager.registerSection()`
* `InsightBuilder`
* 本地缓存 `InsightPack`

官方明确给了 item pane 自定义 section API，这一块优先级很高。([Zotero][1])

## Phase 3：Save to Note / Annotation

* `NoteWriter`
* `AnnotationWriter`
* 统一模板

## Phase 4：Repo Binding

* `RepoSection`
* `RepoService.bindRepo()`
* `RepoService.indexRepo()`

## Phase 5：Paper-Code Align

* `ContextAssembler` 接入 `repoContext`
* `askCodeAlign()`

## Phase 6：Workspace 面板

* 卡片对象化
* 顺序调整
* 回源跳转

# 8. 第一版必须坚持的约束

这几个约束能帮你少走很多弯路。

### 8.1 不要一开始做重画布

先做 `WorkspaceCard[]`，再决定要不要自由布局。

### 8.2 不要一开始做复杂 PDF 解析

先拿到：

* 当前选区
* 当前页文本
* item metadata
* 简单 chunk

### 8.3 不要一开始做多模型编排

只留 provider 抽象层，默认一个 chat model。

### 8.4 所有 AI 结果必须保留 source anchors

否则后面回跳 Zotero reader 会很麻烦。

### 8.5 Item Pane 优先用官方 API

不要手搓 DOM 注入。Zotero 官方已经明确建议走官方 section/info-row API。([Zotero][1])

# 9. 你下一步最值得马上做的三件事

第一，先把仓库空骨架搭出来。
第二，只实现一条闭环：**选中段落 → AI 解释 → 保存到 note**。
第三，再补 item pane 的 `InsightSection`。

这三步跑通后，你这个插件就不再是“概念设计”，而是真正进入可迭代阶段了。
